# 공용 학습자료 분류 전수 검토

관측: 2026-09-19 18:03 KST / 09:03 UTC. 운영 DB의 owner_id IS NULL인 자료 9건(공개 8건, 숨김 검증 자료 1건)과 공개 코스 1건을 확인했다. 개인 문장은 조회·수정하지 않았다.

## 발견·수정

- 콘텐츠 3~7: 받침 발음 예문 1~5의 category가 NULL이었다. 본문, practice_examples의 순서, 예문 세트 revision 1, step 303 및 course 301 ‘받침 발음 기초’를 대조했다.
- 5건을 FINAL_CONSONANT로 수정했다. content_type=CLASS_PRACTICE, learning_focus=PRONUNCIATION, 본문·제목·예문 ID·revision은 유지했다.
- 원인은 deploy/example-tts/publish-course-301.sql의 practice_contents INSERT가 category를 생략한 것이다. 등록 스크립트에 FINAL_CONSONANT를 명시하도록 수정했다. 이미 발행된 세트에는 이 스크립트를 재실행하지 않는다.
- 운영 변경은 기존 NULL 및 코스 연결 조건을 검사한 단일 트랜잭션으로 수행했다. 등록된 예문 본문·제목 변경을 막는 DB trigger를 해제하지 않았다. category 메타데이터 변경은 현 제약이 허용한다.

## 검토 결과

| 대상 | 판정 |
| --- | --- |
| 3~7 받침 발음 예문 | 카테고리 누락 수정 완료 |
| 101 된소리 ㅆ 연습 | 본문 ‘쌀쌀한 … 쑥쑥 … 씻었습니다.’ 및 목표 ㅆ과 TENSE_CONSONANT 일치 |
| 102/103 오늘의 경제 뉴스 | 이전 수정 NEWS / ECONOMY / PRONUNCIATION 유지 확인 |
| 코스 301 받침 발음 기초 | PRONUNCIATION 분류 일치 |
| 숨김 콘텐츠 1 | 운영 검증용 자료로 보존, 공개 학습자료 변경 대상에서 제외 |

현재 공개 자료에 이외의 명백한 분류 오류는 확인되지 않았다. 경제 뉴스 102/103은 동일 제목·본문의 중복 자료지만 분류와 별개이며 기존 세션 참조 보존을 위해 병합·삭제하지 않았다. 분석 미지원이라는 이유만으로 정상적인 억양 자료를 발음 자료로 재분류하지 않았다.

## 검증·영향

- 변경 후 공개 자료 8건 모두 category가 존재한다(빈 카테고리 0건).
- 관련 content detail/list/next/recommendation 캐시 패턴을 조회했으며 이번에는 제거할 키가 0개였다.
- 기존 TTS 작업 5건 모두 GENERATED를 유지한다. 본문 변경이나 새 음성 생성은 수행하지 않았다.
- 기존 사용자 세션·녹음·분석 이력은 변경하지 않았다.
- 등록 SQL 변경은 diff 정적 검토를 수행했다. 새 발행을 검증 목적으로 운영에서 실행하지 않았다.
- 이번 작업에는 추가 코드 배포·서비스 재시작·음성 분석 호출이 없다. 운영 DB 정정은 적용됐고 등록 스크립트 수정은 로컬 변경이다.
