## GPT가 실제 생성한 피드백

> 이번에는 ‘콩을’의 ‘콩’ 받침 ㅇ을 집중해서 연습해 보세요. 제공된 자동 정렬에서는 이 받침에 대응하는 소리를 찾지 못했고, 해당 시각도 표시되지 않았습니다. 이것만으로 실제로 받침을 빠뜨렸다고 단정할 수는 없습니다.
>
> 목표 발음에서 받침 ㅇ은 소리가 있는 비음 [ŋ]입니다. ‘을’의 첫 글자 ㅇ처럼 자음 소릿값이 없는 경우와 다릅니다. 일반적으로는 ‘코’의 모음을 낸 뒤 혀 뒤쪽을 입천장 뒤쪽에 붙여 입안의 공기 통로를 막고, 공기를 코로 내보내며 ‘콩’을 완성합니다. 입술을 꼭 다물어 만드는 소리는 아닙니다. 이는 목표 발음 방법이며, 사용자의 혀 위치나 기류에서 오류가 확인되었다는 뜻은 아닙니다.
>
> ‘코—콩’을 번갈아 말하며, ‘콩’ 끝에서만 코로 울리는 받침이 이어지는지 확인해 보세요. 연습할 때는 받침을 잠깐 유지한 다음 ‘콩—을’로 연결하고, 익숙해지면 늘이지 않고 ‘콩을’이라고 자연스럽게 말해 보세요. 확인 기준은 ‘ㅗ’에서 바로 끝나지 않고 받침의 울림이 남는지, 그리고 ‘을’ 앞에 별도의 ‘그’ 같은 소리를 덧붙이지 않는지입니다.

GPT는 실제 생략·혀 위치 오류를 단정하지 않고 일반 목표 발음과 연습을 제공했다. 입술 수치를 이용한 별도 교정은 제시하지 않았다. 음소별 영상 연결이 없으므로 해당 수치에 근거한 입술 교정 품질을 이번 결과로 평가할 수 없다.
