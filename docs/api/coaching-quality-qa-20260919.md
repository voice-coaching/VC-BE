## 결론

**두 영상의 실제 처리와 GPT 피드백 생성은 확인했지만, 발음 품질과 영상 교정 기준을 모두 통과한 상태는 아니다.**

- 두 영상의 모호한 `ㅇ 삭제`를 확정 교정 대상으로 사용하지 않았다.
- 영상 2는 영상 1보다 감지된 발화 범위가 짧았다. 그러나 정렬 등 근거가 불확실해 판단을 보류한 위치가 훨씬 많았다. 코칭 항목이 적다고 발음이 더 좋다는 뜻은 아니다.
- 40점 입술 추출은 실행됐다. 현재 약 30fps 영상의 20ms 음소 구간에는 0~1 프레임만 있어 음소별 연속 움직임을 검증하기 부족했다.
- 기존 입술 참조는 독립 평가 근거가 없어 `NOT_VALIDATED`를 유지한다. 입 벌림 오류나 개인별 조음 원인을 확정하지 않았다.
- 같은 사람·장비·장소라는 사용자 확인을 반영했다. 녹음 순서는 확인되지 않아 두 파일의 차이를 학습 효과로 해석하지 않았다.

## 속도·쉼 측정과 두 녹음 비교

16kHz mono PCM16을 WebRTC VAD 2.0.10으로 측정했다. 20ms 프레임, 기본 mode 1, 200ms 이상 내부 비음성 구간을 집계하고 mode 0~3의 민감도를 함께 확인했다.

| 측정값 | testvideo1 | testvideo2 |
| --- | ---: | ---: |
| 실제 오디오 길이 | 4.843초 | 2.709초 |
| 첫~마지막 감지 발화 범위, mode 1 | 3.800초 | 2.560초 |
| 발화로 분류한 시간 합, mode 1 | 3.320초 | 2.400초 |

| 같은 지표의 mode 0~3 범위 | 3.42~4.36/초 | 5.08~8.23/초 |
| 200ms 이상 내부 비음성, mode 1 | 1개 / 480ms | 0개 |
| 200ms 이상 내부 비음성, mode 2·3 | 0개 | 0개 |

두 번째 영상이 더 짧은 범위에 발화를 담았다는 방향은 모든 mode에서 같았다. 분자는 대본 음절 수이며 실제 발화 전사는 검증하지 않았다. 따라서 이 값은 정확한 실제 발화 속도나 정상/과속 판정이 아니다.

영상 1의 480ms는 mode 0·1이 60~200ms를 발화로 잡아 생긴 200~680ms의 간격이다. mode 2·3에서는 초기 구간을 발화로 잡지 않는다. **실제 문장 중간 쉼이라고 확정할 수 없다.** 마지막 20ms 미만의 불완전 프레임도 무음으로 계산하지 않고 미분류로 남긴다.

비교기는 문장 해시·측정 정책·VAD 버전/설정이 같은 경우에만 변화량을 제공한다. 같은 PCM을 재사용하면 새 녹음으로 비교하지 않는다. 사용자 확인은 같은 사람·장비·장소까지이며 촬영 순서·교정 전후 관계는 미확인이다. `improvementJudgment=null`을 유지한다.
