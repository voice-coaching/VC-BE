# 관리자 공용 콘텐츠 수정·삭제

이슈 #173. V65 적용 필요. 관리 대상은 owner_id가 없는 NEWS/SENTENCE/ANNOUNCER/CLASS_PRACTICE다. 개인 문장은 기존 소유자 API로 관리한다. 프론트 변경과 운영 데이터 직접 수정은 포함하지 않는다.

## 수정

`PATCH /api/admin/contents/{contentId}`는 기존 `{version,content,reason}` 계약을 유지한다. DRAFT/PUBLISHED/HIDDEN 모두 수정할 수 있으며 status와 최초 publishedAt은 유지한다. type 변경은 409이며 분류/필수 필드 검증은 유지한다. 공개 원문을 수정하기 위해 새 초안을 만들 필요가 없다.

원문이 변경되면 tts_revision을 증가시키고 기존 reference_audios에 retired_at을 기록한다. 퇴역 음성은 관리자/일반 재생·대표 지정에서 제외한다. 제목/설명 등만 바꾸면 음성은 유지한다. 진행 중인 이전 TTS 작업은 완료 시 현재 개정/삭제 여부를 재검사하며 잘못된 음성을 다시 연결하지 않는다. 미완료 수동 업로드도 기존 원문 해시 검사를 적용한다. 이미 발급한 S3 URL 자체를 즉시 취소하는 기능은 아니다.

## 삭제

```http
DELETE /api/admin/contents/{contentId}
Authorization: Bearer <accessToken>
Content-Type: application/json
```

```json
{"version": 3, "reason": "더 이상 제공하지 않는 문장"}
```

성공: 200 ApiResponse, data:

```json
{"id": 279, "version": 4, "deletedAt": "2026-11-02T09:00:00Z"}
```

version과 deletedAt은 서버 응답을 사용한다. 삭제 후 목록·상세 조회 및 편집/재공개/재삭제는 404다. 삭제에 별도 복구/완전 삭제 API는 없다. 콘텐츠를 숨김으로 전환하고 deleted_at을 남기는 방식이며 기존 학습/분석/예문/음성 행·S3 파일을 물리 삭제하지 않는다. DELETE 응답을 잃으면 새 삭제를 자동 재시도하지 말고 관리자 상세의 404로 적용 여부를 확인한다.

- 400: 사유/버전 누락 등 입력 오류
- 401: 서명 토큰/유효 세션 없음
- 403: 현재 ACTIVE ADMIN 권한 없음
- 404: 대상 없음, 삭제됨, 개인 콘텐츠
- 409: 오래된 version, 허용하지 않는 유형 변경
- 503: 저장소 실패. 변경과 감사 기록은 같은 트랜잭션으로 롤백

## 조회와 기록

삭제 콘텐츠는 관리자/일반 카탈로그·상세·추천/다음 콘텐츠·인기 뉴스 및 기준 음성 조회에서 제외한다. 신규 세션은 현재 콘텐츠를 잠금 조회하여 삭제와 경합을 직렬화한다. 기존 세션과 분석 결과는 제거하지 않는다.

공용 세션은 전체 원문과 당시 updated_at을 보관하여 콘텐츠 수정 뒤에도 동일한 원문/프롬프트로 평가한다. 마이그레이션 이전 세션은 업그레이드 시점 원문을 고정한다. 이전에 이미 덮어쓴 원문을 복원하는 기능은 아니다. 개인 문장은 평문 snapshot을 만들지 않는다. 기록 화면 제목은 기존 콘텐츠 관계를 사용하므로 관리자가 바꾼 제목이 표시될 수 있다.

클래스 예문 관계와 식별자는 보존한다. 목록에서 삭제 콘텐츠만 제외하므로 전체 문장 수는 items.length를 사용하고 order 간격을 허용한다. 남은 문장이 없으면 녹음을 시작하지 않는다. 예문 세트 자체를 새로 발행하거나 삭제 콘텐츠를 자동 대체하지 않는다.

## 프론트 후속 작업

- 공개/숨김 콘텐츠에도 편집 폼을 제공하고 기존 원문 잠금/새 초안 강제 분기를 제거한다.
- 기존 폼 계약과 version·사유 확인은 유지한다. 저장 후 최신 상세/음성 목록을 다시 조회한다.
- 삭제 버튼은 확인 대화상자에서 사유를 받고 현재 version을 DELETE body로 전달한다. 성공 후 목록으로 이동하고 목록/상세 캐시를 갱신한다.
- 원문을 변경한 아나운서 콘텐츠는 새 음성을 등록해야 한다. 기존 음성이 자동으로 새 문장에 연결됐다고 표시하지 않는다.
- 개인 문장의 관리자 수정/삭제 기능이나 역할 변경 기능을 추가하지 않는다.
