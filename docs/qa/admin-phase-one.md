- Swagger 관리자 인증·201·409·필수 version 및 공지 요청 sections 스키마 검증.

## 재현 방식

일반 테스트와 JAR 빌드는 Java 21에서 실행한다.

```text
./gradlew test bootJar
```

관리자 PostgreSQL 검증은 별도 폐기 가능한 loopback 클러스터에서만 수행한다. `VC_BE_TEST_POSTGRES_URL`에 `jdbc:postgresql://127.0.0.1:<port>/<test-db>`, 별도 테스트 USER/PASSWORD를 설정하고 다음 테스트만 선택한다.

```text
./gradlew test --tests '*AdminPostgresMigrationTest'
```

전체 테스트에 해당 환경변수를 일괄 설정하면 기존 PostgreSQL 전용 테스트들도 활성화된다. 일부는 Spring datasource 재설정·DB 이름 등 별도 fixture 조건을 요구하므로 일반 전체 실행과 분리한다.

초기 확인에서 기존 로컬 AI 계약 파일 4개의 CRLF/LF 차이로 고정 해시 검사가 실패했다. 내용이 원격 develop과 동일하고 줄바꿈만 다름을 확인한 뒤 원격 기준 바이트로 복원했으며 계약 정의·기대 해시·검증 강도는 변경하지 않았다. 최종 일반 전체 테스트에서 해당 검사는 통과했다.

## main 기준 호환성 (2026-11-02)

`SecurityConfig.java`는 main 버전을 그대로 유지한다. 관리자 컨트롤러에서는 서명된 Bearer Access Token, 유효한 로그인 세션, 토큰의 ADMIN 역할과 현재 DB의 활성 ADMIN 계정을 확인한다. `X-User-Id`로 관리자 신원을 대신할 수 없다. 회원 팝업은 서명된 로그인과 기존 활성 회원 검사를 적용한다. 테스트 이용등급 `admin`은 관리자 권한이 아니다.

관리자 마이그레이션은 V62(감사 기록·편집 버전), V63(기준 음성 업로드), V64(알림·팝업)이며 main의 V61은 변경하지 않는다. 인증 회귀 테스트는 실제 서명 토큰과 세션을 사용하며, 미인증·무서명 토큰·회원 ID 위장·세션 폐기·현재 역할 변경을 검증한다.

main의 기존 일반 조회 정책은 이번 작업에서 변경하지 않는다. 특히 기존 기준 음성 목록 API는 공개 상태를 검사하지 않으므로, 관리자에서 등록한 초안의 음성도 일반 조회에 포함될 수 있다. 관리자 API의 접근 통제와 일반 조회의 공개 상태 필터링은 별개이며, 초안의 비공개 보장은 현재 main 기준으로 제공되지 않는다.

## 회원 상세·탈퇴 추가 검증 (#175)

- 관리자만 회원 원래 이메일과 로그인 연결 정보를 조회하고 일반 회원은 403인지 확인한다.
- 비밀번호·제공자 내부 ID·토큰·원본 음성 주소가 상세 및 관계별 기록에 없는지 확인한다.
- 탈퇴 확인 번호 불일치, 최신 시각 불일치, 본인 계정, 존재하지 않는 회원, 미인증·권한 없음 요청을 거부한다.
- 정상 탈퇴는 익명화 및 기존 정리 절차를 호출하고, 재요청은 중복 정리·감사 기록을 만들지 않는다.
- 기존 수정 시각 null 회원을 처리하고, 감사 저장 실패 시 회원 상태가 롤백되는지 확인한다.
- 로컬 PostgreSQL의 실제 마이그레이션 스키마에서 관계별 기록 조회 SQL을 실행한다.
- 운영 회원 탈퇴·운영 DB 변경은 이 자동 검증에서 수행하지 않는다.
