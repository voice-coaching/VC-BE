# WebP decoder fixture

`sample.webp` is `1.webp` from TwelveMonkeys ImageIO 3.13.1:
https://github.com/haraldk/TwelveMonkeys/blob/twelvemonkeys-3.13.1/imageio/imageio-webp/src/test/resources/webp/1.webp

The upstream repository license is included as `LICENSE-TwelveMonkeys.txt`.
This fixture is used only to exercise actual WebP decoding, cropping, and PNG encoding.
